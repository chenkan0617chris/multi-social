# AI自媒体一条龙

将人的选题判断/拍摄与可自动执行的制作步骤衔接。总技能负责简报、阶段状态和交接，不替代子技能的专业操作；调用本技能不会自动发布任何历史素材。默认面向侃侃Chris的真实AI实践，具体受众和目标按本条简报。

## 入口与自动化范围

- **还没拍**：用`ai-topic-plan`合并问2–3个缺失问题，给3–5个候选；用户选题或明确委托代选后，调用`ai-video-script`交付口播稿和拍摄清单，停在等待用户拍摄。不能假装自动获得未提供的真人素材。
- **拍好了**：锁定指定素材包/项目，直接从`ai-talking-edit`开始；从实际讲话提炼标题，不要求重做选题或重录。多候选无法判断时只问文件选择，不凭“最新下载”猜。
- **续作/修正**：先读项目记录及实际平台/时间线状态，从缺失或失效阶段继续；只改封面就不重剪视频，已公开内容不能当作未提交重发。
- **工作坊示范**：按同一链路分阶段展示输入、产物和关键判断；不为演示去公开发帖。

首次需要时合并确认：目标人群/目的、语言与平台、是否含动画、预计长度、是否连续执行及发布模式。复用已知偏好，不把“这一次全中文”扩大成所有未来任务必须中文。默认中文口播，分发语言按本次简报明确；不擅自生成英文配音。

“全自动”“一条龙”“拍完直接处理”表示已授权范围内连续制作，可跳过ChatCut指南的逐阶段确认。保留录制/素材缺失、题目未选且未委托、登录验证、实质范围变化等真正依赖用户的节点。不得用运行时长或无回复代替选择与批准。

发布模式：默认`prepare_only`（上传填好，停在最终提交前）。用户明确说“这条制作完成后直接发布到这些平台”且素材包、账号范围、语言与公开受众明确时，可记录`publish_after_checks`并在检查通过后连续执行，不必重复请求同一授权。“全自动制作”或笼统“以后自动发”不构成任意未来内容的发布授权。更具体的本次“不要发”始终优先。

## 阶段路由

按技能名称从当前技能目录定位并读取；下面本地子技能链接可直接使用。不要固定ChatCut缓存版本、模板ID或依赖不存在的工具。缺依赖就说明并继续独立可完成的步骤，不安装收费服务或假装已执行。

| 阶段 | 技能 | 输入→交付/完成依据 |
|---|---|---|
| 方向/选题 | [ai-topic-plan](../ai-topic-plan/SKILL.md) | 真实经历+受众→候选与选定题目 |
| 写稿/拍摄准备 | [ai-video-script](../ai-video-script/SKILL.md) | 选题→口播稿、拍摄清单→等待用户素材 |
| 主剪/字幕 | [ai-talking-edit](../ai-talking-edit/SKILL.md) | 实际素材→稳定口播时间线、准确字幕、剪辑记录 |
| 观点动画 | [ai-point-motion](../ai-point-motion/SKILL.md) | 稳定时间线→已合成的多样动画、动效分镜；用户不需要则跳过 |
| 核验/导出 | 当前ChatCut verification + export技能 | 实际音画检查→真实成片文件、导出状态；不要假定导出完成 |
| 封面 | [cover-generate](../cover-generate/SKILL.md) | 实际主题+本人素材/授权背景→本次语言/平台所需封面，核对实际比例与裁切 |
| 分发 | [multi-social](../multi-social/SKILL.md) | 已验证成片+封面→逐平台待审核或获准后发布结果 |

依赖顺序不能倒：主剪改动会使字幕/动画时间码失效；成片内容实质变化会使封面、文案和既有批准待复核。先把上游修正，再只重做受影响阶段。字幕/动画需协调布局。封面制作可在内容稳定后与导出独立推进，但不用“并行”掩盖未核验产物。

沿用已确认人物图和背景；缺背景但用户已授权你设计时可设计新背景，未授权且素材缺失时只问必要素材。默认不强制全套七/八张；按本次平台与语言调用cover-generate的数量覆盖规则。B站双比例、Instagram长竖版等规则以对应技能为唯一来源，不在此复制一份易过期表。

## 状态与交接

在`~/Documents/Social Media/YYYY-MM-DD-主题/`保存同一内容包，日期按用户时区Australia/Sydney；已指定包则复用，保留原片。开始/续作时读取[项目记录模板](references/project-record.md)，创建或更新`项目记录.md`；已有`发布清单.md`继续作为发布状态的唯一明细，不覆盖历史尝试。

每阶段记录真实输入、输出路径或项目ID、版本/时间、验证证据、下一步和阻断。不要只写“完成”而无产物。发布状态从multi-social记录，未知提交结果先查平台，不能重试制造重复。

停止/缺工具时保存可续作状态，不承诺离线后台自动继续，不创建定时任务。最终给成片、封面、项目记录链接与简短平台状态，区分已制作、已上传、已提交审核、已公开及未验证；不要把技能写好称为全链路已实测。

## 调用例子

- `$ai-content-pipeline 我想给悉尼华人讲AI做自媒体，先问我几个问题，给3–5个选题。`
- `$ai-content-pipeline 这是拍好的素材，中文、蓝色观点动画，一条龙制作并准备全平台，先不要发布。`
- `$ai-content-pipeline 继续这个内容包，只修改B站宽横封面，停在投稿前。`
- `$ai-content-pipeline 将本次指定素材包连续制作，核验后直接发布到我确认的这些账号和平台。`
